# refused_gate

The forecast-correction method as a Python package: `gates.py` (gate designs), `ladder.py` and `analysis.py` (gate ladders and tests), selection rules (PART, prequential, nested hold-out), `probabilistic.py` and `energy.py` (quantiles, reserve, deviation energy), `stats.py`, `data.py` (loaders for the Indian series and the comparison data), `paths.py` (folder layout) and `guard.py` (the lock on held-out data).

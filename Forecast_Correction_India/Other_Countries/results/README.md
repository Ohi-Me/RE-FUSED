# results

| Folder | What it is |
|---|---|
| `confirm/` | **Final** confirmatory results; verdicts in `confirm/analysis/verdicts.json` |
| `confirm_sensitivity/` | The logged sensitivity runs DC1 and DC1b |
| `dev/` | Development runs |
| `surrogate/`, `x0/` | Semi-synthetic checks and the re-analysis of the earlier stage |
| `RESULTS_SHA256.txt` | Hashes of the frozen results (paths use the working folder names) |

Per-row results built from NYISO data are not shared (NYISO's terms); summaries are.

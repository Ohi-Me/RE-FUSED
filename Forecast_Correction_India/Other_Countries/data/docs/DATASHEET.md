# Datasheet — RE-FUSED data

Every file used is listed with size, SHA-256 and a writer-independent content hash in `DATA_MANIFEST.csv`
(generated by `code/scripts/data/make_data_manifest.py`). Splits and roles are fixed in
`design/02_preregistration.md` (frozen) and summarised in the manuscript (Table "Datasets, roles and splits").

## 1. NYISO Market Information System (development and confirmatory)

| Item | Value |
|---|---|
| Source | NYISO public MIS, `http://mis.nyiso.com/public/` (monthly zip archives of daily CSV files) |
| Products | `isolf` (7-day hourly zonal load forecast, one file per issue day), `palIntegrated` (hourly integrated actual zonal load), `damasp` (day-ahead ancillary service prices) — Jan 2019 to Aug 2026; `damlbmp_zone` (day-ahead zonal LBMP) and `realtime_zone` (real-time zonal LBMP, 5-min) — Jan to Aug 2026 |
| Units | 11 NYISO load zones (CAPITL, CENTRL, DUNWOD, GENESE, HUD VL, LONGIL, MHK VL, MILLWD, N.Y.C., NORTH, WEST) |
| Acquisition | `code/scripts/data/fetch_nyiso.py [start] [end]`; each month stored as parquet in `data/raw/nyiso/<product>/YYYYMM.parquet` |
| Processing | `build_nyiso_panel.py`: local prevailing time, repeated autumn hour averaged; ISO forecast issued on day D−1 for day D (alignment verified by the lag of minimum error); real-time prices averaged to hourly |
| Roles | development: test 2025 (validation 2024); confirmatory: test 1 Jan – 31 Aug 2026 (gates fitted on 2025, learned correctors trained on 2019–2024) |
| Licence | Public data; NYISO's legal notice grants no redistribution licence. Raw files are **not** redistributed; the package contains the download script, per-month content hashes and all derived results |
| Known issues | NYISO may revise archived files; a re-download can therefore differ. Compare `content_sha256` per month in `DATA_MANIFEST.csv` to locate revisions |

## 2. Open Power System Data — time series (confirmatory)

| Item | Value |
|---|---|
| Source | OPSD time series package, version 2020-10-06, 60-min single index; https://doi.org/10.25832/time_series/2020-10-06 |
| Content used | ENTSO-E Transparency actual load and TSO day-ahead load forecast per area |
| Acquisition | `code/scripts/data/fetch_public.py` (SHA-256 written next to the file) |
| Eligibility | both series ≥ 95 % complete over 2015–2019; overlapping aggregates excluded → 46 non-overlapping areas (`refused_gate.data.OPSD_UNITS`) |
| Roles | confirmatory 2019 (train 2015–17, validation 2018, test 2019) and 2020 (train 2015–18, validation 2019, test Jan–Sep 2020); fresh semi-synthetic grid (X1) on a 12-area substrate of the 2019 split |
| Licence | Attribution required (Open Power System Data, 2020); see the package metadata for the terms of the underlying sources |
| Known issues (deviation DC1) | Corrupt values in the source, e.g. SK actual load 2,170,811 MW on 2020-02-01 20:00 and FR 158,000 MW on 2020-07-07 17:00. A plausibility filter defined from 2015–2017 actual load only (outside [0.5 × area 0.1 % quantile, 1.5 × area 99.9 % quantile] → missing) flags 181 actual-load and 690 TSO-forecast values over all years (2019: 43 and 468; 2020: 56 and 0). The pre-registered analysis did **not** apply the filter; the filtered re-run is a logged sensitivity analysis (`design/04_deviations.md`) |

## 4. Development-only data (not used for any confirmatory claim)

| Dataset | Source and role |
|---|---|
| India daily generation | 20 aggregated series of a balanced panel of generating units, derived from Central Electricity Authority daily reports via the India Data Portal; used in RE-FUSED-6 and for RE-FUSED development only. Read from the RE-FUSED-5 data folder (`refused_gate.paths.RE-FUSED5_DATA`); only processing scripts and derived results are shared |
| ETTh1, ETTh2 | Zhou et al. (2021), ETDataset repository; 7 channels each, 70/10/20 % split; development only. Obtain from the original repository under its licence |

## 5. Processed panels

| File | Built by | Content |
|---|---|---|
| `data/processed/nyiso_load_panel.parquet` | `build_nyiso_panel.py` | NYISO hourly load, ISO forecast, prices, reserve prices |
| `data/processed/opsd_load_panel.parquet` | `build_confirmatory_panels.py` | OPSD actual load and TSO forecast per area (unfiltered) |
| `data/processed/uci_load_panel.parquet` | `build_confirmatory_panels.py` | hourly UCI client load |
| `data/processed/nyiso_learned_baselines_{dev,confirm}_s0.parquet` | `scripts/dev/make_learned_baselines.py` | out-of-sample NHITS, PatchTST, TiDE, DLinear, LightGBM and Chronos-Bolt forecasts |

Processed confirmatory panels were built without inspecting outcomes; the loader (`refused_gate.data`) refuses to return
confirmatory rows unless the pre-registration hash, git tag and environment flag match (`refused_gate.guard`).

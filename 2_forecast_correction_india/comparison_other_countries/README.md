# Comparison study: the same method on data from other countries

This folder holds the first pre-registered test of gated forecast correction. It used public data from outside
India, because suitable hourly Indian data had not yet been built. It is kept so that the Indian results can be
compared with how the same method behaves elsewhere. It is not part of the Indian evidence.

| Data | Period tested | Source |
|---|---|---|
| NYISO zonal load (New York) | January – August 2026 | NYISO market information system |
| 46 European transmission forecast areas | 2019 | Open Power System Data |
| 60 electricity clients | 2014 | UCI ElectricityLoadDiagrams20112014 |
| a fresh semi-synthetic grid | — | generated by the code |

| Folder | What it holds |
|---|---|
| `01_audit/` | The audit of the earlier stage and the audit of this confirmatory run |
| `02_design/` | Research design, the frozen pre-registration (`prereg-v1`), development log, deviations DC1 and DC1b |
| `03_data/docs/` | Datasheet and data manifest (the raw files are not redistributed; `../04_code/scripts/data/` downloads them) |
| `05_configs/` | The configuration of every run |
| `06_results/` | Development, confirmatory and sensitivity results, with `RESULTS_SHA256.txt` |
| `07_figures/`, `08_tables/` | Generated figures and tables |
| `12_logs/` | Run logs |

**Result:** 19 of 23 pre-registered tests supported. On NYISO a coarse per-zone correction cut deviation energy by
about 854 GWh a year and 99 % upward reserve by 234 MW at almost the same reliability (99.2 % against 99.3 %), but
it did not lower two-settlement imbalance cost. Under the logged sensitivity run DC1b two partition criteria fall
just below their thresholds (0.848 and 0.746 against 0.85 and 0.75).

To run code against this folder, set `REFUSED_GATE_STUDY=foreign` (the default).

# RE-FUSED-8, laptop stage — preserved material

The India programme began on the laptop as the folder `REFUSED8`, and moved to the H100 cluster on
17 September 2026. From 18 September the cluster copy was the only project folder, and it is now
`India_Grid_Study/`.

Kept here is only what the cluster copy does not contain.

| Folder | What is in it | Why |
|---|---|---|
| `00_admin/` | The laptop-era `STATUS.md` and `RESUME.md` | The dated record of the first four days, before the log moved to the cluster copy |
| `01_audit/` | `01_alignment_audit.md` | The audit that compared the CPRI proposal, the earlier pilot and RE-FUSED-7, and set the five objectives |
| `12_logs/` | The data-acquisition logs and the first training-queue logs | Evidence of how the raw data were collected, and of the laptop runs that were later redone on the cluster |

## What was deliberately not kept

- `03_data/` — 5.6 GB, byte-identical to the cluster copy's `data/`. Verified file by file: all 18,105 raw
  files match by name, size and content.
- `04_code/`, `02_design/`, `05_configs/`, `13_env/` — superseded by the cluster copy, which is what the
  pre-registration hashes.
- `06_results/dev/` — 743 MB of round-1 development results produced on the laptop. The cluster reran round 1
  in full, and the pre-registration hashes the cluster's files, not these.

The rest of this stage is kept in the local research archive.

## Status

Superseded. Nothing here supports a current result; it is the record of how the programme started.
